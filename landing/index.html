Problem

ArcGIS web maps are collaborative, but the release workflow usually isn't.

Teams change basemaps, layers, symbology, popups, and extent settings every week. Without version control, those edits are hard to review, risky to test, and painful to roll back.

“What changed?”

Portal tells you something was modified. GitMap shows the exact properties, layers, and settings that changed.

“Can I test this safely?”

Create a branch for experiments, staging updates, or stakeholder review before anything touches production.

“Can we undo it?”

Use gitmap revert, branch history, and commit snapshots to recover from bad releases without guesswork.

“How do we compare environments?”

Diff branches or commits to review staging vs production map state before you publish.

Workflow

A Git-shaped workflow for map configuration.

GitMap doesn't try to reinvent release discipline. It adapts the familiar Git loop to ArcGIS web map JSON so GIS teams can work more intentionally.

1

Clone or initialize

Pull down an existing web map with gitmap clone or start a new repository with gitmap init.

2

Branch for changes

Use branches to isolate basemap swaps, popup edits, symbology experiments, or release prep work.

3

Review diffs

Check exactly what changed before you commit or merge. No more comparing screenshots and memory.

4

Merge and push

Promote approved changes back to the main branch and sync them to ArcGIS Online or Portal.

Install

Up and running in a few minutes.

Install from PyPI, set your ArcGIS credentials, then clone a map and inspect its history like you would a code repo.

# Install and confirm the CLI is available
pip install gitmap
gitmap --version

# Set ArcGIS Online or Portal credentials
export PORTAL_URL=https://your-org.maps.arcgis.com
export ARCGIS_USERNAME=your_username
export ARCGIS_PASSWORD=your_password

# Clone a map, branch, and review the diff
gitmap clone abc123def456
cd MyWebMap
gitmap branch feature/hydrology-update
gitmap diff main feature/hydrology-update

What you need

  • Python 3.11, 3.12, 3.13, or 3.14
  • ArcGIS Online or Portal for ArcGIS access
  • A web map item ID to clone or a new map to initialize

FAQ

Short answers to the first questions people usually ask.

Does GitMap version the underlying feature data?

No. GitMap versions the web map item JSON: layer references, symbology, popups, visibility, extent, and related configuration.

Does it work with ArcGIS Online and Enterprise?

Yes. GitMap is built for ArcGIS Online and Portal for ArcGIS workflows.

Is this only for developers?

It is a CLI-first tool today, so it fits best for technical GIS staff, GIS developers, and teams comfortable with lightweight scripting.

Can I try it safely?

Yes — start with a non-critical map, branch before making changes, and review the diff before merging or pushing.
