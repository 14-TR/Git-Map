## How to use this section

The rest of the docs explain what each command does. These examples show how the commands fit together in real GIS team workflows.

A good rule of thumb:

- use **Getting Started** when you are new to Git-Map
- use **CLI Reference** when you already know the command you need
- use **Examples** when you know the outcome you want but need the playbook
